# AnyaTalk Issues

[日本語](#日本語) · [English](#english) · [中文](#中文)

## 日本語

AnyaTalk Lite（VRChat 用リアルタイム翻訳）と AnyaTalk VR Reader の不具合報告・要望を受け付ける場所です。ソースコードはここにはありません。

- **不具合の報告**：[New issue](../../issues/new/choose) から「不具合報告」を選んでください。
- **要望**：「機能の要望」を選んでください。
- 日本語・English・中文、どの言語でも大丈夫です。

### 報告の前に

- **API キーは絶対に貼らないでください**（Groq・Fish Audio など）。ログを貼るときも、キーが含まれていないか確認してください。
- ログの場所：`%LOCALAPPDATA%\AnyaTalk\logs\anyatalk-lite.log`
- バージョンはダウンロードした ZIP のファイル名（例：`AnyaTalk-1.0.0-windows-x64-lite-gpu.zip`）でわかります。
- 同じ内容の報告がすでにないか、[既存の issue](../../issues?q=is%3Aissue) も見てみてください。

## English

This is where bug reports and feature requests for AnyaTalk Lite (the real-time translator for VRChat) and the AnyaTalk VR Reader go. There is no source code here.

- **Report a bug:** [New issue](../../issues/new/choose) → "Bug report".
- **Ask for a feature:** choose "Feature request".
- Japanese, English or Chinese are all fine.

### Before you post

- **Never paste API keys** (Groq, Fish Audio, …). Check any log you paste for keys first.
- The log is at `%LOCALAPPDATA%\AnyaTalk\logs\anyatalk-lite.log`.
- Your version is in the name of the ZIP you downloaded (e.g. `AnyaTalk-1.0.0-windows-x64-lite-gpu.zip`).
- Please check [existing issues](../../issues?q=is%3Aissue) for the same report.

## 中文

这里用于接收 AnyaTalk Lite（VRChat 实时翻译）和 AnyaTalk VR Reader 的问题反馈与功能建议。这里没有源代码。

- **报告问题**：在 [New issue](../../issues/new/choose) 中选择「不具合報告 / Bug report」。
- **功能建议**：选择「機能の要望 / Feature request」。
- 日语、英语、中文都可以。

### 提交之前

- **请勿粘贴 API 密钥**（Groq、Fish Audio 等）。粘贴日志前请确认其中不含密钥。
- 日志位置：`%LOCALAPPDATA%\AnyaTalk\logs\anyatalk-lite.log`
- 版本号见下载的 ZIP 文件名（例如 `AnyaTalk-1.0.0-windows-x64-lite-gpu.zip`）。
- 请先查看[已有的 issue](../../issues?q=is%3Aissue) 是否已有相同反馈。

Pull requests are not accepted here. AnyaTalk is made by Pipira.
