# AnyaTalk — issues & feedback

This repository only collects bug reports, questions and feature requests for **AnyaTalk** by Pipira.
It contains no source code, and pull requests are not accepted.

- BOOTH shop (download and PDF guides): https://anyapipira.booth.pm/
- [Open an issue](../../issues/new/choose)

## 日本語

AnyaTalk（無料の AnyaTalk Lite と AnyaTalk VR Reader）の不具合報告・質問・要望を受け付けるリポジトリです。ソースコードは含まれず、プルリクエストは受け付けていません。

- 「New issue」からテンプレートを選んで、日本語でも英語でもお気軽にどうぞ
- 製品とバージョン（ダウンロードした ZIP のファイル名、例：`AnyaTalk-1.0.0-windows-x64-lite-gpu.zip`）、Windows と GPU、VRChat のデスクトップ／VR、再現手順を書いてください
- ログは `%LOCALAPPDATA%\AnyaTalk\logs\anyatalk-lite.log` にあります
- **API キー（Groq・Fish Audio など）や `.credential` ファイルは絶対に貼らないでください。** ログを貼る前にキーが含まれていないか確認してください
- ダウンロードした ZIP や VR Reader のファイルは添付しないでください（再配布になります）。スクリーンショットや短い動画は歓迎です
- 公開の場です。個人情報やログイン情報は書かないでください

## English

This is where to report bugs, ask questions and request features for AnyaTalk (the free AnyaTalk Lite and the AnyaTalk VR Reader). It has no source code, and pull requests are not accepted.

- Choose a template under "New issue". Japanese or English are both welcome
- Include the product and version (from the ZIP name, e.g. `AnyaTalk-1.0.0-windows-x64-lite-gpu.zip`), your Windows and GPU, VRChat desktop or VR, and the steps to reproduce
- The log is at `%LOCALAPPDATA%\AnyaTalk\logs\anyatalk-lite.log`
- **Never paste API keys (Groq, Fish Audio, …) or your `.credential` file.** Check any log for keys before you paste it
- Please do not attach the downloaded ZIP or VR Reader files (that would be redistribution). Screenshots and short videos are welcome
- Issues are public: do not post personal information or credentials
